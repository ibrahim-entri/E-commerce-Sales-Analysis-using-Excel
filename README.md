# E-commerce Sales Analysis (Excel Project)

## 📊 Project Overview
This project analyzes e-commerce sales data using Microsoft Excel. The goal is to identify sales trends, top-performing products, and customer purchasing behavior.

## 🛠 Tools Used
- Microsoft Excel
  - Pivot Tables
  - Charts
  - Functions (SUM, IF, VLOOKUP)

## 📈 Key Analysis
- Sales trend analysis
- Top-selling products
- Customer purchase behavior
- Revenue insights

## 📁 Files Included
- Excel file with cleaned data and analysis
- Dashboard with charts and visuals

## 💡 Key Insights
- Identified high-performing products
- Found monthly sales trends
- Analyzed customer buying patterns

## 🎯 Conclusion
This project helps understand business performance and supports better decision-making using data.
